1. Apa yang dimaksus persamaan linear#

Jawaban#

Persamaan linear adalah persamaan aljabar di mana setiap suku memiliki pangkat 1 dan ketika persamaan ini digrafikkan, hasilnya selalu berupa garis lurus. Inilah alasan mengapa persamaan ini disebut persamaan ‘linear’.#

Secara umum, bentuk persamaan linear satu variabel adalah:#

ax + b = 0

Sedangkan bentuk persamaan linear dua variabel adalah:#

ax + by = c

dengan:#

  • a, b, dan c adalah konstanta (bilangan real),

  • x dan y adalah variabel,

  • a dan b tidak keduanya bernilai nol.

Persamaan linear dua variabel jika digambarkan dalam bidang koordinat akan menghasilkan sebuah garis lurus. Apabila terdapat dua persamaan linear dua variabel yang disusun menjadi satu sistem, maka disebut Sistem Persamaan Linear Dua Variabel (SPLDV), yang penyelesaiannya berupa titik potong kedua garis tersebut.#
